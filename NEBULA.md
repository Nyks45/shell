# Parts from Nebula

Parts of this shell are ported from **Nebula** by LilaccFlowerr
(https://github.com/LilaccFlowerr/Nebula), which is licensed under the GNU Affero General Public
License v3.0. Those parts remain under the AGPL-3.0; each ported file names its source.

- `modules/lock/`: the lock screen (black hole, orbiting widgets, glass cards).
- `components/nebula/`: shared pieces (glass surfaces and, as the integration goes on, the
  islands, tiles and morphing controls).

The integration plan and what is still to come: `dev/plans/nebula-integration.md` in the
workspace this fork is developed in.
